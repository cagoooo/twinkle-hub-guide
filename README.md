# ✦ Twinkle Hub 教師指南

> 📌 **建置版本：2026.06.04-1**（依據 `version.json`）

把**台灣的官方資料**接進 AI 助教的認識與使用宣導網站，對象為**全校老師、學生與家長**。

🌐 **線上網址**：https://cagoooo.github.io/twinkle-hub-guide/

## 這是什麼

[Twinkle Hub](https://hub.twinkleai.tw) 是台灣團隊 Twinkle AI 打造的 MCP 資料閘道，讓 AI 助理（如 Claude）能直接查詢台灣官方資料：

- 📅 國定假日、補班、國曆↔農曆、24 節氣
- 📝 6.4 萬份國家考試考古題（含教師檢定）語意搜尋
- 🔤 簡體↔台灣正體轉換、數字↔國字大寫
- 🗺️ 郵遞區號、行政區、避難收容所查詢
- 🏛️ 政府開放資料（實價登錄、政府採購、立法院等）

本站把這些內容整理成適合師生家長閱讀的介紹，並提供安裝與使用步驟。

## 特色

- 📱 完整 RWD 響應式：手機、平板、桌機皆已實測（無水平捲動、漢堡選單、彈性版面）
- 👩‍🏫🧒👨‍👩‍👧 分眾說明：老師、學生、家長各自的好處
- 🪶 單檔零依賴：純 HTML/CSS/JS，GitHub Pages 直接託管

## 聲明

本網站僅為**教學推廣整理**，非 Twinkle AI 官方網站。服務功能與計費請以 [官方公告](https://hub.twinkleai.tw) 為準。

### 給 AI Agent 的接手指南

1. 先閱讀本 README、`AGENTS.md`（若有）、套件腳本與部署設定。
2. 先辨識教材、題庫、提示詞或設定資料的單一來源，避免只改畫面上的副本。
3. 調整內容時維持適齡、可讀性、無障礙與個資保護。
4. 修改後驗證教師操作流程、學生操作流程，以及桌機、平板、手機的可用性。
5. 不要捏造尚未存在的功能；README 與實作有落差時，應同時更新文件。
6. 提交前只納入本次任務檔案，並記錄實際執行過的驗證。

### 安全與資料注意事項

- 不要提交 `.env`、服務帳號、API 金鑰、token、學生個資或正式環境匯出資料。
