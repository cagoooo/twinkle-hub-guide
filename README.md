## 這是什麼

[Twinkle Hub](https://hub.twinkleai.tw) 是台灣團隊 Twinkle AI 打造的 MCP 資料閘道，讓 AI 助理（如 Claude）能直接查詢台灣官方資料：

- 📅 國定假日、補班、國曆↔農曆、24 節氣
- 📝 6.4 萬份國家考試考古題（含教師檢定）語意搜尋
- 🔤 簡體↔台灣正體轉換、數字↔國字大寫
- 🗺️ 郵遞區號、行政區、避難收容所查詢
- 🏛️ 政府開放資料（實價登錄、政府採購、立法院等）

本站把這些內容整理成適合師生家長閱讀的介紹，並提供安裝與使用步驟。
